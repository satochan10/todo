# ✨ かわいいTodo - やることリスト ✨

子ども向けのかわいいTodoアプリです。

## ローカル起動方法

### 方法1: HTTPサーバーを使用（推奨）

**Pythonがインストールされている場合:**

```bash
# プロジェクトディレクトリで実行
cd docs
python3 -m http.server 8000

# ブラウザで開く
# http://localhost:8000
```

**ポート8000が既に使用されている場合:**

```bash
# ポート8000を使用しているプロセスを確認
lsof -i :8000
# 出力例:
# COMMAND   PID   USER   FD   TYPE             DEVICE SIZE/OFF NODE NAME
# Python  69157 satoru    4u  IPv6 0x5fc91db79d0acee1      0t0  TCP *:irdmi (LISTEN)

# 古いプロセスを終了
kill -9 69157

# 改めてサーバーを起動
python3 -m http.server 8000
```

**または別のポートで起動:**

```bash
python3 -m http.server 3000
# http://localhost:3000 でアクセス
```

### 方法2: Node.jsのhttp-server

```bash
npm install -g http-server
cd docs
http-server

# ブラウザで開く
# http://localhost:8080
```

### 方法3: Live Server（VSCode拡張機能）

1. VSCodeで「Live Server」拡張機能をインストール
2. `docs/index.html`を右クリック
3. 「Open with Live Server」を選択

## 機能

### ✅ やることリスト
- 入力欄に書いて「➕ 追加」（またはEnter）でタスクを追加
- チェックを入れると完了。完了したタスクは元に戻せない（ポイントの二重取り防止）
- 「すべて／残ってる／完了」で表示を切り替え
- 「🗑️ 完了したのを削除」で完了済みタスクをまとめて削除
- ドラッグで並び替え（スマホはタッチ操作でも可）
- データはFirebase（Firestore）に保存され、どの端末でも同じ内容が表示される

### ⭐ ポイントとキャラクター
ポイントは2種類ある。画面上部の黄色い枠に両方表示される。

| 種類 | 表示 | 増える | 減る | 使い道 |
|---|---|---|---|---|
| 🌱 せいちょうポイント | 「これまでに あつめた ○P」 | ポイントをもらったとき | 減らない | キャラの進化 |
| 👛 つかえるポイント | 「つかえるポイント ○P」 | ポイントをもらったとき | 特典・ヘルプで使ったとき | 特典との交換 |

- タスクを1つ完了すると **1P**
- 18:00〜21:00 は **ポイント2倍**（画面上部にお知らせが出る）
- せいちょうポイントが貯まるとキャラが進化する（🐚 → 🦀 → 🦞 → … → 🚀、全30段）
  - 進化に必要なポイントはだんだん増える：1段目 5P、2段目 10P、3段目 15P…（レベルNになるには合計 5×(N−1)×N÷2 P、最後の🚀は合計2175P）
  - 枠には今のレベルと、次の進化までのバー・残りポイントが表示される
  - 進化するとお祝い画面が出る（前のキャラが光って消え、新しいキャラが登場＋紙吹雪）
- ポイントを使ってもキャラは戻らない
- Firestore の `app/settings` に `points`（つかえる）と `totalPoints`（せいちょう）として保存。`totalPoints` がない古いデータは、初回読み込み時に `points` の値で作られる

### 🎁 ポイント特典
上部のポイント表示をタップすると特典を選べる。確認ダイアログでOKすると、つかえるポイントが引かれる（せいちょうポイントは減らない）。

| 特典 | 必要ポイント |
|---|---|
| 📺 YouTube 30分 | 10P |
| 💵 100円 | 20P |

※ バクバクチャレンジの「❓ ヘルプ」でもポイントを使う（5P）。

### 📋 おでかけまえチェック
- 出かける前の持ち物リスト。行をタップするとチェックが付く
- 全部チェックするとお祝いメッセージが出る
- 「クリア」でチェックを全部外す（持ち物自体は消えない）

### 🍚 バクバクチャレンジ
ごはんを20分以内に食べ終わるチャレンジ。20分のカウントダウンタイマーが表示される。

- **▶️ スタート**：タイマー開始
- **⏸️ いちじていし**：タイマーを止める。止めている間はスタートが「▶️ さいかい」になる
- **⏹️ ストップ**：食べ終わったら押す。「たべおわりましたか？」の確認で「はい」を押すと、かかった時間に応じてポイント獲得（お祝い演出あり）。「いいえ」ならタイマーが続きから動く。確認中はタイマーが止まる
- **❓ ヘルプ**：「5Pつかってyoutubeをみますか？」の確認で「はい」を押すと5P使って、YouTubeチャンネル[ちろぴの](https://www.youtube.com/@tiropino)の動画をランダムに1本再生する。5P未満のときは「ポイントがたりないよ」と出て見られない
  - ヘルプのダイアログはタイトル部分をつかんで自由に動かせる。後ろは暗くならず、動画を見ながらタイマーやボタンを操作できる
  - 「とじる」で再生が止まる。バクバクチャレンジを閉じるとヘルプも閉じる
- **とちゅうでおわる**：確認ダイアログ（おわり／つづける）のあと、ポイントなしで終了。確認中はタイマーが止まる
- チャレンジ中（スタート後〜ストップまで）は「とじる」を押せない。背景タップでも閉じない

| 残り時間（ストップした時） | かかった時間 | ポイント |
|---|---|---|
| のこり10分以上 | 〜10分 | 20P |
| のこり8分まで | 〜12分 | 16P |
| のこり6分まで | 〜14分 | 12P |
| のこり4分まで | 〜16分 | 8P |
| のこり2分まで | 〜18分 | 4P |
| さいごまで | 〜20分未満 | 2P |
| 時間切れ | 20分 | 0P |

※ チャレンジのポイントは18〜21時の2倍の対象外。

### 🔒 管理者モード
右上の ⚙️ ボタンからパスワード **`2019`** を入力すると管理者モードになる（画面が茶色＋金色の配色に変わる）。ページを再読み込みすると通常モードに戻る。

管理者モードでできること：
- **タスクの削除**：各タスクに「🗑️ 削除」ボタンが出る（通常モードでは非表示）
- **🌅 朝のタスク／🌙 夜のタスク**：登録しておいたタスクをボタン1つでまとめて追加
- **⚙️ タスク編集**：朝・夜のタスクの内容を追加・削除
- **おでかけまえチェックの編集**：持ち物の追加・削除ができる
